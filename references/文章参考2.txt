Frontmatter 头部有强制固定规则；正文主体 Markdown 是自由发挥，但是业界有推荐的标准章节模板（不强制）
Frontmatter（YAML 头部）硬性固定，不能乱
必须用 `---` 包裹，必填 2 个字段：`name`、`description`**，少一个加载失败
---
name: code-audit
description: 污点代码审计，执行Source→Propagation→Sink数据流漏洞分析。在用户要求代码审计、污点分析时启用。
# 下面是可选自定义字段（平台私有，OpenCode会忽略不认识的key）
opencode/slash: true
opencode/autoinvoke: false
claude/slash: code-audit
---
约束：
- `name`：只能小写字母、数字、短横线 `-`，最长 64 字符，不能空格
- `description`：最长 1024 字符，**强烈建议写清楚两件事：技能做什么 + 什么时候触发**，这是模型自动判断要不要加载 skill 的依据
`---` 之后正文（Markdown 部分）完全自由，无强制语法
正文没有固定关键字、没有强制章节，就是直接注入给模型的系统指令，纯 markdown 随便写：
- 可以写一级标题、二级标题、列表、表格、代码块、规则、示例、限制、检查清单
- 没有强制要求必须写 `## Instructions`，不写也能跑
- 可以中文，可以英文，混合写都行
但是为了审计 skill 可读性稳定、模型不容易跑偏，社区通用推荐模板（**推荐但非强制**）

1、三类形态：框架、编排、Skills

第一类，自主渗透框架。自己带 Agent 调度、记忆、工具链，你说目标它跑流程。代表是 PentAGI、PentestGPT、Strix、PentestAgent、CAI、ARTEX。这类最像"操作系统"，重，但完整。

第二类，工具编排 / MCP 平台。不自己造 agent，而是把 nmap、nuclei、sqlmap、metasploit 这些老牌工具用 MCP 接给大模型指挥。代表是 HexStrike AI、DarkMoon、MCP Security Hub、RedTeam-Agent。这类轻，落地快，适合接进你现有的工作流。

第三类，Agent Skills。不是独立软件，是一堆写给 Claude Code / Cursor 的"技能文件"，让编码助手化身渗透副驾。代表是 0xSteph/pentest-ai-agents。这类最轻，装完就能用，适合个人。还有两个 awesome 清单专门做汇总，懒得一个个翻的可以直接看清单。
